# 阅读笔记

此目录保存获准落盘的 Markdown 阅读记录。导师式笔记使用 `<paper-id>-guided.md`，苏格拉底式笔记使用 `<paper-id>-socratic.md`。paper-id 建议采用已核实的年份和简短题名；未知时用 `paper-001` 等中性编号，不编造元数据。

使用对应技能中的完整模板，至少记录：

- 原始文件名或私有路径、版本、可读取范围及缺失材料；作者、年份、DOI 未核实则明确标注。
- 来源位置：PDF 页码或印刷页码（注明类型）、章节、图号与面板；补充材料单独定位。
- 作者原始结论、实验直接证据、推测及 AI 假设，分别标记，保留证据边界与替代解释。
- 问题、用户原始回答、具体纠正及修正后的认识；区分导师建议和用户已确认的理解，不伪造回答。
- 当前阶段、待回答问题、跳过项、待验证研究假设与下次阅读入口。

先读取已有笔记，再增量更新；两个阅读模式可互相引用，不互相覆盖。没有实际阅读的章节标记“未读”，没有核实的信息标记“未核实”。

笔记以个人概括为主，仅保留必要短引文和来源位置，不复制整篇论文。笔记也可能含未公开研究思路或敏感结果：保存前确认权限，未经授权不提交、推送、发布或上传外部服务。此目录当前未被 Git 自动忽略，敏感笔记优先保存到用户指定的仓库外私有目录。
