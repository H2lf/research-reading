# 原始论文与补充材料

此目录用于保存用户有权使用且允许在当前环境落盘的 PDF 及 Supporting Information（补充材料）；不要求必须把论文放入仓库，技能也可读取用户指定的私有文件路径。

建议命名为 `<paper-id>.pdf` 和 `<paper-id>-SI.pdf`，paper-id 可采用已核实的年份与简短题名；元数据未知则用 `paper-001` 等编号。同一论文的不同版本应显式区分，不覆盖原始文件。阅读笔记放在 `notes/`，并记录来源版本和页码类型。

优先使用用户提供的原始 PDF。核对正文、图像、图注和补充材料是否齐全；扫描件或不清晰页面需要可辨认的页面材料，不能用模型记忆补全。DOI、题名和作者仅从可核实来源记录。

保存前确认版权、许可及保密要求。可在线阅读或已购买不代表允许公开再分发；不擅自上传出版商 PDF、未公开稿件或实验室内部材料。

此目录当前未配置 Git 忽略规则：放入目录不代表不会被提交。敏感或受版权限制的资料优先保存在用户指定的仓库外私有目录，不自动执行暂存、提交、推送或公开发布。若需要仓库内私有存储及额外忽略规则，应在另行授权后配置。
